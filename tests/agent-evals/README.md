# Agent 2.0 核心评测基线

本目录冻结 Agent 1.0 与 2.0 共用的七类任务输入和指标口径。每轮正式基准运行必须记录：代码 SHA、数据集版本、模型、温度、功能开关、成功检查明细、输入/输出 token、端到端耗时和回滚结果。

## 执行规则

1. 每个场景至少运行 5 次；创作质量场景使用匿名双人盲评。
2. `requiredChecks` 任一硬检查失败，则该次任务记为失败，不用“基本完成”替代。
3. token 取 Agent Run 的累计 usage；耗时取 `startedAt → finishedAt`；工具耗时从持久化事件下钻。
4. 触发回滚的场景必须验证正文、标题、顺序、统计和 revision，而非只看接口成功。
5. 正式结果单独保存为脱敏 JSON，不提交真实小说正文或用户对话。

当前 P0 冻结了场景与汇总算法；需要真实模型和可用测试数据库的基准运行在具备对应环境后执行，不以虚构数字填充 1.0 基线。
