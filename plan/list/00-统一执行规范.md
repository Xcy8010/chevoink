# 统一执行规范

开始任何代码任务前，先阅读 `plan/01-产品方案与PRD.md`、`plan/02-技术架构方案.md`、`plan/03-品牌与界面规范.md`、`plan/05-UIUX设计规范.md`、`plan/07-AI配置安全与长上下文方案.md`、`plan/08-env变量设计与密钥托管规范.md`、`plan/09-数据模型与接口契约初稿.md` 与 `plan/list` 下本窗口对应清单，只按本窗口负责目录开发。

当前允许进入公网测试开发阶段，可进行服务器初始化、域名解析、HTTPS、数据库接入、部署脚本与上线相关改动。完成公网测试开发并验收通过后，可直接上线使用。

所有 AI 请求必须走本地后端，真实 API Key 只能放服务端 `.env`，不得写进前端、浏览器缓存、README、截图或日志。

公网测试与正式上线阶段必须继续遵守服务端密钥托管、最小暴露面和环境隔离原则；严禁将真实密码、SSH 私钥、数据库密码、API Key 写入仓库文档或前端代码。

严禁 emoji icons、塑料感、容器反复嵌套；手机 / 平板 / 电脑必须按不同任务重排布局，不得机械缩放。

所有用户可见界面文案必须面向最终用户，禁止把开发阶段说明、测试提示、窗口分工、占位说明、待接接口、mock 提示、契约说明、执行约束、初始化状态等研发信息直接渲染到页面中；如果某区域暂未接入真实能力，只允许使用克制的产品级空状态或直接隐藏，不允许把“施工现场文案”展示给用户。

改代码前先确认不越界、不覆盖别的窗口文件。

第一轮默认只开 A、B、C 三个窗口并行：

- A 管全局壳与设计系统
- B 管发现 / 详情 / 阅读
- C 管后端、数据模型与接口契约

只有当 A 的全局壳稳定、C 的接口契约稳定、B 能正常挂载页面后，才进入第二轮再开 D、E。
