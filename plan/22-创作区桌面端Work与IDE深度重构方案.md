# 创作区桌面端 Work 与 IDE 深度重构方案

> 状态：已完成
> 日期：2026-08-25
> 范围：创作区桌面网页端与桌面 APP；手机端保留现有成熟交互，仅共享能力与视觉语言
> 前置：`21-创作区与Agent-2.0企业级迭代方案.md` 的 Agent 2.0 数据与工具能力已经落地

## 1. 产品目标

把创作区从“网站页面中的三栏编辑器”升级为全屏创作操作系统：Work 以 Agent 任务为主，IDE 以正文编辑为主；两种模式共享作品、章节草稿、Agent Session、ChangeSet、记忆和自动保存状态，切换时不丢上下文。

桌面端进入 `/studio` 后隐藏站点顶部导航与全局侧栏，由 Studio Shell 占满可用视口。右上角提供明确的“返回首页”，左上角提供 Work / IDE 模式切换。自动保存继续运行，但界面不展示保存按钮、自动保存按钮或保存状态胶囊。

## 2. 选定视觉方向

### 2.1 Work：Codex 式任务工作台

- 采用选定概念 A 的清晰三分区和概念 C 的高密度工具时间线。
- 主背景为低对比深灰/浅灰工作面，分区用单像素分隔线，不使用层层圆角卡片。
- 对话始终是视觉中心；工具、推理、变更和证据作为扁平行展示。
- 左任务区和右检查区默认折叠为 44–48px 图标轨道，用户点击展开；展开宽度控制在 220–280px，并支持拖拽调宽。
- 右检查区标签顺序固定为：作品、上下文、变更、记忆。

### 2.2 IDE：全屏写作 IDE

- 采用选定概念 D：顶部命令栏、左作品树、中间正文、右 Agent Dock、底部轻状态栏。
- 正文是最大表面，树和 Agent Dock 可折叠、可调宽，不叠加网站卡片壳。
- Agent Dock 顶部只保留“对话 / 记忆”两个标签。

### 2.3 原创 Agent 标识

- 不使用机器人脸、现成 Codex 图标或 DeepSeek 图标。
- 使用代码原生 SVG：以“墨滴/笔尖 + 轨道节点”为母题，表达创作、推理与记忆连接。
- 单色 `currentColor`，在深浅主题、16px 工具栏和 36px 空状态下均清晰；纯装饰场景隐藏于读屏。

## 3. 桌面信息架构

### 3.1 全局 Studio Command Bar

左侧：Work / IDE 分段开关、作品切换、当前卷章。
右侧：发布主操作、作品页、预览阅读、封面工坊、一键导出、作品设置和返回首页。低频操作进入一个扁平下拉菜单。
不出现：沉浸模式、手动保存、自动保存状态。

### 3.2 Work 布局状态

```text
┌ Command Bar ──────────────────────────────────────────────┐
│ [任务轨] [Agent 对话] [章节/记忆查看器，可选] [检查轨]    │
└───────────────────────────────────────────────────────────┘
```

- 默认：任务轨折叠、检查轨折叠、查看器关闭，对话获得最大宽度。
- 展开任务轨：展示会话列表、运行状态和新建任务。
- 展开检查轨：展示作品树、当前上下文、变更摘要或记忆入口。
- 点击作品树章节：在对话右侧打开正文查看器；不强制切换 IDE。
- 点击记忆：在同一查看器位置打开关系图；每次记忆数据更新时间变化时重新渲染。
- 查看器可关闭；正文查看器支持编辑，仍走现有章节 revision 与自动保存链路。
- 选中正文后出现“添加到对话”，把作品、卷、章和选区文字以引用形式加入当前 Agent 输入框。

### 3.3 IDE 布局状态

```text
┌ Command Bar ──────────────────────────────────────────────┐
│ [作品树] [正文编辑器] [Agent Dock: 对话 / 记忆]           │
└ Status Bar ───────────────────────────────────────────────┘
```

- 作品树按卷 → 章组织，保留新增、移动和管理动作。
- Agent Dock 的“对话”复用同一个 Agent Session；“记忆”显示同一关系图组件。
- 正文选择内容可写入 Agent 输入，Work/IDE 切换后输入与引用不丢失。

## 4. 推理与工具视觉

参考 DeepSeek Harness 的信息层次，仅采用交互模式，不引入其预览期包：

- 推理过程是独立的紧凑折叠行，不与工具调用混为一张卡片。
- 收起态显示“思考”与当前/首句摘要；运行中跟随最新一行，并使用低强度扫光。
- 展开态显示缩进、弱色正文；尊重 `prefers-reduced-motion`。
- 工具调用显示图标、动作名称、目标、状态和耗时；详情按需展开。
- 审批、危险操作和失败仍使用更高视觉权重，避免被普通思考行淹没。

## 5. 记忆关系图

### 5.1 数据

新增只读图谱契约与端点，输出：

- `nodes`：人物、地点、组织、物品、事件等实体，包含显示名、类型、摘要、置信度和更新时间。
- `edges`：实体关系，包含关系类型、方向、状态、来源和更新时间。
- `version/updatedAt`：用于前端判断是否需要更新布局。

服务端只返回当前登录作者所属作品的数据，不暴露完整正文；查询沿用现有 StoryEntity / EntityRelation 数据，不另造一套记忆真相源。

### 5.2 展示

- SVG 自适应关系图，节点按实体类型着色，连线展示关系；支持缩放、拖动画布、选择节点查看摘要。
- 数据为空时提供明确空状态与“先让 Agent 分析作品”的引导。
- 提供可访问的实体/关系列表作为图形的文本等价表达。
- Agent Run 活跃时低频刷新；run 完成、记忆工具完成或章节保存触发主动失效，避免常驻高频轮询。

## 6. 响应式边界

- `lg` 及以上启用本方案桌面 Shell。
- 手机网页和 APP 继续使用现有底部导航、92dvh 工具舱、键盘和安全区逻辑。
- 手机端共享新增的记忆图谱数据与原创 Agent 标识，但不强行塞入桌面四栏；记忆以全屏页/抽屉展示。
- 平板横屏优先使用 IDE 双栏或 Work 对话 + 单侧抽屉，禁止四栏同时挤压。

## 7. 实施批次

### 批次 A：Shell 与视觉基础

1. Studio 路由桌面全屏化，隐藏 AppShell 导航和外层留白。
2. 新建 Studio Command Bar、原创 Agent Mark、共享桌面色彩与分隔线语义。
3. 删除桌面沉浸入口与保存控件，保留自动保存逻辑。

### 批次 B：Work 工作台

1. 左右折叠轨、持久化展开状态与拖拽宽度。
2. 右侧四标签检查区与作品树。
3. 可编辑章节查看器、关闭/调宽、选区加入对话。
4. Agent 对话与 Timeline 扁平化。

### 批次 C：IDE 与推理表达

1. IDE 顶部命令栏、作品树、编辑器、Agent Dock、状态栏重排。
2. Agent Dock 对话/记忆 Tab。
3. Work/IDE 统一推理折叠行和工具调用行。

### 批次 D：记忆图谱

1. shared 契约、只读 API、所有权校验。
2. SVG 图谱、详情面板和无数据/错误/加载态。
3. 与 run、章节保存和记忆更新事件联动刷新。

### 批次 E：验证

1. 单元/集成测试覆盖宽度约束、图谱映射、权限和选区引用。
2. 四闸：`tsc --noEmit` → `npm test` → `npm run build` → `npm run lint`。
3. 1440×900、1280×800、深浅主题截图对比；检查默认折叠、展开、章节查看器、记忆图和 IDE。
4. 手机 390×844 回归现有主要入口，确认键盘、安全区与底栏无倒退。

## 8. 硬约束与不做清单

- 不改 Agent 工具名称、权限等级和服务端执行语义。
- 不改 `AGENT_AUTO_APPROVE=true` 的产品决策。
- 不改变 admin `/auth/login` 的手工状态机校验。
- 不引入 DeepSeek Harness 的预览期 UI 依赖；只适配其经验证的信息层次。
- 不复制第三方图标或品牌资产；Agent 标识原创实现。
- 不另建记忆数据库；图谱是现有记忆模型的只读投影。
- 不重写手机创作区；本轮只做必要的共享能力接入与回归。
- 不删除 `ImmersiveComposer.tsx` 历史实现，先移除入口和引用，待稳定版本后另批清理。

## 9. 验收标准

- 桌面进入创作区无站点顶部导航，Work/IDE 均铺满视口，右上角可返回首页。
- Work 左右区域初始折叠，展开后不超过约定宽度且可拖拽；刷新后宽度保持。
- 作品树按卷章展示；点击章节可在 Work 内查看、编辑并把选区加入对话。
- IDE Agent 区只有“对话 / 记忆”；两模式共享 Session、草稿和引用。
- 记忆关系图能显示真实实体与关系，并在记忆版本更新后刷新。
- 发布、作品页、预览阅读、封面工坊、一键导出均有可发现入口。
- 界面不存在沉浸、保存、自动保存状态控件；自动保存功能正常。
- 推理过程紧凑可折叠，工具、审批、变更层级清楚；减少动画模式可用。
- 四闸全绿，桌面主要状态完成截图验收，手机端无明显回归。
