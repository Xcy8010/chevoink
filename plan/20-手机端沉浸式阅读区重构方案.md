# 20-手机端沉浸式阅读区重构方案（对标番茄小说）

> 范围：**仅手机端**阅读链路（`/novel/:novelId/read/:chapterId`，`useDevice() === 'mobile'` 分支）。平板 `ReaderTablet` 与桌面 `ReaderDesktop` 保持现状不动。
> 铁律：阅读进度云同步、听书引擎、评论体系、创作区预览（`from=studio`）等既有能力**只复用不破坏**；所有新交互在触屏手势不可用时必须有按钮兜底。

### 0.2 与番茄小说的差距（本次要解决的问题）

1. **没有"代入页"**：点开始阅读直接落到正文，缺少番茄式的书籍封面页（封面+作者+简介+热评+左滑开始阅读），进入阅读缺乏仪式感。
2. **退出无书架挽留**：直接退出，没有"加入书架，方便下次查看"的确认弹窗，书架转化链路缺失。
3. **滚动式阅读，无翻页**：整章竖向滚动、一章一屏到底，长章节容易跟丢；左右滑当前语义是"切章"，与翻页心智冲突。
4. **无仿真翻页动画**：没有跟手的书页翻动效果，缺乏"翻实体书"的沉浸感。
5. **信息层级不沉浸**：顶部通栏进度条常驻打扰；没有"当前页/全书总页数"、时间、电量这类番茄式静默信息层。
6. **默认字号偏小**：默认"舒适"17px，番茄默认视觉在 20px+，读起来不够轻松。
7. **段落操作弱**：段评入口是段尾小气泡（点击段落才显现），没有长按选段的操作面板；**复制、划线完全没有**。

## 1. 产品目标与信息架构

### 1.1 新的阅读流（手机端）

```
详情页/书架/首页继续阅读
        │ 开始阅读
        ▼
┌─ 阅读器容器（横向 Pager）──────────────────────────────┐
│ [代入页] ← 左滑 → [第1页][第2页]…[第N页] ← 左滑 → 下一章首页 │
│  (仅从"未读/首章无进度"进入时作为第 0 页；               │
│   有进度时直接落在对应页，代入页可右滑回看)               │
└──────────────────────────────────────────────────────┘
        │ 退出（返回键/退出按钮）
        ▼
   在书架？──是──▶ 直接退出
        │否
        ▼
 「加入书架，方便下次查看」弹窗
   [暂不加入]→退出   [加入书架]→入架后退出
```

### 1.2 页面信息层（沉浸态，替代现有顶部进度条）

- **左下角**：`当前全书页码/全书总页数`（如 `3/11242`），小字、低对比度。
- **右下角**：实时时间 `HH:MM` + 电池电量图标（Battery API 不可用时只显示时间）。
- **右上角**：`…` 更多按钮（半透明、常驻但弱化），点击弹出菜单：**听书 / 阅读设置 / 目录 / 评论**。
- **删除**：现有顶部通栏 `ReaderProgressBar`（手机端）。
- 轻点屏幕中央仍可呼出完整控制栏（保留退出/上一章/下一章等兜底按钮）；左右 1/4 区域轻点 = 翻上一页/下一页（番茄同款）。

## 2. 核心技术方案

### 2.1 分页引擎（最大难点）

**目标**：每页固定容量、精确排版、字号/屏幕/章节变化时重排；并能给出"全书页码"。

**方案：离屏测量 + 逐段二分填充**

1. 新建 `useChapterPaginator(paragraphs, layout)` hook：
   - 在一个与正文视口同宽高、同字体设置的**离屏测量容器**（`visibility:hidden` 绝对定位）中逐段落灌入文本；
   - 每页可用高度 = 视口高 − 上下安全区 − 底部信息层高度；
   - 段落放不下时对该段做**字符级二分切割**（利用 `Range.getBoundingClientRect` 或逐步截断测量），切割点尽量落在标点后；
   - 产出 `pages: ReaderPage[]`，每页记录 `{ pageIndex, blocks: [{ paragraphIndex, startChar, endChar }] }` —— **保留段落索引映射**，段评/听书高亮/划线才能继续工作。
2. 重排触发：`fontScale`、`tone`（不触发）、视口尺寸（`visualViewport resize`）、章节内容变化；重排后按"当前阅读字符偏移"定位回同一位置，不跳页。
3. 性能：单章 ≤ 2 万字，测量一次 < 50ms 量级；用 `requestIdleCallback` 分片测量 + 缓存（key：`chapterId+updatedAt+fontScale+viewportW×H`，存内存 Map 即可）。

**全书总页数与全局页码（番茄 `3/11242` 语义）**

- 精确分页只做**当前章**；其余章节用 `wordCount ÷ 当前排版实测每页均字数` 估算页数。
- `全书总页数 = Σ(各章估算页数)`，`当前全局页码 = 前序章节估算页数之和 + 当前章内精确页号`。
- 依赖：reader payload 的 `chapterList` 需带每章 `wordCount`（`Chapter.wordCount` 字段已存在，若接口未返回则在 `api/routes` 的 reader payload 中补上，属只读扩展）。
- 字号切换后总页数会变——与番茄行为一致，属预期。

**进度兼容**：`scrollPercent` 字段语义平滑复用为"章内进度百分比 = 当前页/本章总页"，云端接口**零改动**；老数据（滚动百分比）换算进新分页定位，误差一页以内可接受。

### 2.2 翻页手势与仿真动画

**手势语义变更（仅手机端）**：左滑 = 下一页，右滑 = 上一页；章末最后一页继续左滑 = 无缝进入下一章第 1 页（预取下一章分页）；章首右滑同理回上一章末页。现有 `useChapterGestures` 的"滑动切章"退役，改为 `useReaderPager` 手势层。

**翻页动画：三种模式，设置面板可选**

| 模式 | 实现 | 默认 |
|---|---|---|
| 仿真 | 当前页作为"翻起的纸"：跟手位移 + `rotateY` 微角度 + 右缘动态阴影（线性渐变模拟纸背卷曲），下层直接是下一页。纯 CSS transform + 单层 canvas 阴影都不用，保持 60fps | ✅ 默认 |
| 覆盖 | 下一页从右侧滑入覆盖当前页（微信读书风格），仅 `translateX` + 投影 | |
| 上下滚动 | 保留现有整章滚动模式（老用户逃生门，进度条信息层同步适配） | |

**跟手细节（真实感的关键）**：
- 手指按下即开始位移（无启动阈值感）；松手按**速度+位移**双阈值判定翻页/回弹（`velocity > 0.3px/ms` 或位移 > 1/3 屏宽）；
- 补间用 `transition: transform 240ms cubic-bezier(0.22,1,0.36,1)`，翻页与回弹同曲线；
- 动画期间锁手势，防连滑撕裂；DOM 结构常驻**前/当前/后三页**，翻页 = 指针平移，无重挂载；
- 与长按选段手势互斥：`pointerdown` 起 500ms 内位移 > 10px 判翻页、否则计长按。

### 2.3 代入页（图一）

作为 Pager 的第 0 页，全屏沉浸底色（跟随 tone），**新组件 `ReaderCoverPage`**：

- **右上角**：功能按钮排（听书 🎧、阅读设置，弱化图标）；
- **中部**：封面大图（带投影）→ 书名 → 作者行（头像+昵称，点击 `navigate('/author/:id')`）→ 数据行（评分/在读人数/字数·状态，复用 `DetailStatsRow` 数据）；
- **简介区**："简介"标题右侧横排作品标签 chips；正文 2 行截断 + "更多"展开；
- **热门书评**：`topComments` 前 3 条（头像/内容/星级），"更多书评" 跳详情页评论 Tab；
- **底部**：胶囊提示 `← 左滑开始阅读`（呼吸微动效）。
- 数据来源：详情页同源接口（React Query 已有缓存则秒出）；**展示条件**：该书无阅读进度（首次读）时进场落在代入页；有进度时落在续读页、代入页仍在第 0 页可右滑回看。

### 2.4 退出书架挽留弹窗（图二）

**新组件 `AddShelfDialog`**（居中 Dialog，非 BottomSheet）：

- 触发点：代入页/阅读页点退出按钮、以及 Android 返回手势（`popstate` 拦截一次）；
- 判定：`getLocalShelf()`/云端书架已含该书 → 直接退出，**不弹**；
- 文案：标题「加入书架，方便下次查看」，副文案「N 人与你共读《书名》」（在读人数字段缺失时降级为「喜欢就加入书架，下次接着读」）；
- 按钮：`暂不加入`（次级，直接退出）｜`加入书架`（品牌色，调 `pushShelfAdd` 后退出 + toast）；
- 每本书每会话最多弹一次（sessionStorage 记忆），不做"永不再弹"（转化优先，与番茄一致）。

### 2.5 沉浸信息层（图四）

**新组件 `ReaderPageChrome`**（每页复用的静默信息层，不随控制栏显隐）：

- 左下 `当前全书页/总页数`，右下 `HH:MM`（`setInterval` 每 30s 对时）+ 电量：`navigator.getBattery()`（Chrome/Android 可用，监听 `levelchange`；iOS Safari 不支持则整体隐藏电池只留时间）；
- 右上 `…` 按钮 → `MoreMenuSheet`：听书（复用 `state.tts`）、阅读设置、目录、评论 四项；
- 字号默认档调整：默认档从 `comfortable(17px)` 改为**新增 `xlarge(22px/行距2.4)` 之下的 `relaxed(19px)`**——具体为字号档位表升级：`17/19/21/23px`，默认 `19px`（仅调整档位表数值与默认值，存储结构不变；老用户已显式选择的档位按 id 映射保持不跳档）。

### 2.6 长按选段操作（图五）

**新交互 `useParagraphLongPress` + `ParagraphActionBar`**：

- 长按（500ms、位移 <10px）某段 → 该段落底色高亮（`color-mix currentColor 14%`）+ 段落上方/下方弹出横排操作条；
- 操作条按钮：
  1. **从本段听**：`state.tts.playFromParagraph(paragraphIndex)`（引擎已支持按段所在批次开播）；
  2. **发段评**：`state.openParagraphComments(paragraphIndex)`（已有能力，直接接线）；
  3. **复制**：`navigator.clipboard.writeText(段落全文)` + toast「已复制」（降级 `document.execCommand`）；
  4. **划线 / 取消划线**：见 2.7，已划线段落该按钮显示"取消划线"；
- 点击空白处/翻页/滚动即关闭；操作条样式为深色胶囊浮层（跟随 tone 自适应对比色）。
- 分页模式下段落可能被切成两页：以 `paragraphIndex` 为操作单元，高亮当前页可见部分即可。

### 2.7 划线（新数据能力）

**新表 `ParagraphUnderline`**（段级划线，不做字级 range——现阶段正文按段渲染，段级实现简单可靠，与"选择对应的段"需求吻合）：

```prisma
model ParagraphUnderline {
  id             String   @id @default(cuid()) @db.VarChar(64)
  userId         String   @map("user_id") @db.VarChar(64)
  novelId        String   @map("novel_id") @db.VarChar(64)
  chapterId      String   @map("chapter_id") @db.VarChar(64)
  paragraphIndex Int      @map("paragraph_index")
  createdAt      DateTime @default(now()) @map("created_at")
  user           User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  chapter        Chapter  @relation(fields: [chapterId], references: [id], onDelete: Cascade)

  @@unique([userId, chapterId, paragraphIndex])
  @@index([userId, chapterId])
  @@map("paragraph_underlines")
}
```

- 接口（挂 `api/routes/users.ts` 或新建 `reader.ts`）：
  - `GET /api/users/me/underlines?chapterId=` → 本章划线段索引数组（进章时随 reader 数据并行拉取）；
  - `PUT /api/users/me/underlines`（body: novelId/chapterId/paragraphIndex）幂等创建；
  - `DELETE /api/users/me/underlines`（同参数）删除；
- 渲染：已划线段落文字加 `border-bottom`/`text-decoration: underline`（虚线、品牌色 60% 透明度，随 tone 自适应）；
- 未登录：点划线引导登录（复用全局登录拦截），本地不做匿名划线。

### 2.8 听书 / 评论 / 目录 / 设置的适配

全部**复用现有组件**，只换挂载点与打开入口：

- 听书迷你条、`TtsControlSheet`、跟读段落高亮在分页模式下继续工作：高亮段落所在页若不是当前页，自动翻到该页（听书自动"翻页跟读"，替代原自动滚动）；
- `ReaderDirectory` / `ReaderCommentsPanel` / `ReaderSettingsContent` 继续走 BottomSheet，从 `…` 菜单与呼出控制栏两处都可进；
- 阅读设置面板新增「翻页方式」选择（仿真/覆盖/上下滚动），存 `reader-settings.ts`（新增 `pageTurnMode` 字段，向后兼容缺省仿真）。

## 4. 交互细节规范（验收口径）

1. **手势仲裁优先级**：长按(500ms 静止) > 水平翻页 > 轻点。轻点分区：左 25% 上一页 / 右 25% 下一页 / 中 50% 呼出控制栏。
2. **翻页动画**：60fps，只允许 `transform/opacity` 参与动画；松手补间 ≤ 280ms；连滑时先完成当前补间的指针提交再受理下一次。
3. **章边界**：进入当前章即空闲预取上下章内容与分页（React Query 已有 5 分钟缓存），跨章翻页无 loading 白屏；确无下一章时最后一页左滑露出"已读完最新章节"页脚回弹。
4. **代入页**：仅本书无进度时作为落点；`from=studio` 预览**不出**代入页与挽留弹窗。
5. **挽留弹窗**：已在书架/未登录游客（游客书架走本地）判定准确；`加入书架` 成功 toast「已加入书架」后 300ms 退出。
6. **信息层**：页码/时间/电量常驻但不随控制栏显隐闪动；听书迷你条出现时右下信息自动上移让位。
7. **进度回写**：翻页防抖 800ms 写 `scrollPercent=页/总页`，语义对老端兼容；退出时强制 flush 一次。
8. **重排恢复**：改字号/旋屏后停留在同一处正文（按字符偏移恢复），不允许跳章跳页超过 1 页。
9. **划线**：操作 200ms 内乐观上屏，失败回滚 + toast；取消划线同段幂等。
10. **无障碍/兜底**：所有手势能力（翻页/退出/换章）在呼出控制栏中均有等价按钮；`prefers-reduced-motion` 时翻页动画退化为瞬时切换。

## 6. 风险与取舍

| 风险 | 对策 |
|---|---|
| 分页测量在低端机耗时 | 分片测量 + 缓存 + 首屏先渲染"估算页"再无感校正 |
| 仿真翻页动画性能 | 只用 transform/阴影渐变，不上 canvas 曲面；卡顿机型引导切覆盖模式 |
| Battery API iOS 不可用 | 特性检测，无则只显示时间（番茄 iOS 同样弱化电量） |
| 全书总页数为估算值 | 与番茄一致的行业惯例；章间误差不影响章内精确页码 |
| 段落被分页切断时的段评/划线/高亮归属 | 一律以 `paragraphIndex` 为准，页内只渲染可见片段的效果 |
| 返回手势拦截弹窗的路由兼容（Android 壳） | 只拦截一次 popstate，弹窗关闭后放行，Capacitor 壳内实测验证 |
| 老用户习惯滚动阅读 | 翻页方式设置保留「上下滚动」，默认仿真但可回退 |
